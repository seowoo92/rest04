### 3. 공통 컴포넌트 구현

#### PageHeader.jsx
- 모든 서브 페이지 공통 헤더 컴포넌트
- props: category(상단 라벨), title(제목), bgText(배경 대형 텍스트)
- 배경 아이보리, 오른쪽에 대형 영문 텍스트 (opacity 조건부)
- 하단 구분선: 얇은 전체 라인 + 왼쪽 머스타드 포인트 선
- 텍스트 fadeSlideUp 애니메이션
- **다크모드 조건부 색상 적용**:
  - bgText: 라이트 `rgba(42,45,67,0.09)` / 다크 `rgba(255,255,255,0.07)`
  - 구분선: 라이트 `rgba(42,45,67,0.12)` / 다크 `rgba(255,255,255,0.08)`

#### DarkGlow.jsx
- 배경 글로우 효과 (라이트/다크 모두 표시, 홈 제외 서브 페이지 전체 적용)
- **초기 구현**: Canvas API + RequestAnimationFrame + MutationObserver
  → 다크모드 전환 시 글로우가 보이지 않는 문제 발생
- **재작성**: CSS `radial-gradient` div 2개 + `@keyframes` 애니메이션 방식으로 교체
  - `useTheme` 훅으로 dark 상태 직접 구독 (MutationObserver 불필요)
  - `glowFloat1` 14s / `glowFloat2` 18s 키프레임 애니메이션
  - 이동 거리 최대 200px, scale 변화 추가로 유영하는 느낌
- **모드별 opacity**:
  - 다크: 코랄 0.18 / 머스타드 0.14
  - 라이트: 코랄 0.22 / 머스타드 0.18

### 7. 다크모드 개선
- `ThemeContext.jsx`: localStorage에 테마 저장/복원
  - 초기값: `localStorage.getItem('theme') === 'dark'`
  - 토글 시: `localStorage.setItem('theme', dark ? 'dark' : 'light')`
- `Layout.jsx`: `position: relative` 제거로 stacking context 해소
  → DarkGlow의 `position: fixed`가 뷰포트 기준으로 올바르게 동작

### 8. SPA 라우팅 개선
- **기존**: `?p=` 쿼리스트링 인코딩 방식
- **변경**: `sessionStorage.redirect` 방식으로 교체
  - `public/404.html`: `sessionStorage.redirect = location.href` 저장 후 루트로 리다이렉트
  - `index.html`: `sessionStorage.redirect` 읽어서 원래 경로로 `history.replaceState` 복원

## 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| 히어로 배경 이미지 안 보임 | GitHub 업로드 시 파일 손상(2B) | VS Code에서 직접 드래그 앤 드롭으로 `src/assets/` 에 추가 |
| 배포 후 서브 페이지 404 | GitHub Pages SPA 라우팅 미지원 | `public/404.html` sessionStorage 리다이렉트로 교체 |
| 다크모드 버튼 텍스트 안 보임 | 하드코딩 색상 `#2A2D43` | CSS 변수 `var(--text)`로 교체 |
| 스냅 스크롤 튕김 현상 | CSS mandatory 방식의 강제 이동 | JS debounce + 방향 감지 방식으로 교체 |
| GitHub Pages 배포 안 됨 | Pages 브랜치가 main으로 설정됨 | Settings > Pages에서 gh-pages 브랜치로 변경 |
| DarkGlow 다크모드에서 안 보임 | Canvas + MutationObserver 방식 불안정, Layout div의 stacking context가 fixed 동작 방해 | CSS radial-gradient + useTheme 훅 방식으로 재작성, Layout에서 `position: relative` 제거 |
| 페이지 새로고침 시 다크모드 초기화 | ThemeContext 초기값이 항상 false | localStorage에 테마 저장/복원 추가 |

## 배운 것
- `react-router-dom` `basename` 설정으로 GitHub Pages 하위 경로 라우팅 처리
- CSS 변수(`:root`, `.dark`)로 다크/라이트 테마 전환 구현
- `position: relative` + `z-index`가 stacking context를 만들어 자식의 `position: fixed` 동작을 방해함
- Canvas + RAF 방식보다 CSS `radial-gradient` + `@keyframes`가 글로우 효과에 더 안정적
- `sessionStorage`를 활용한 SPA 라우팅 404 우회가 쿼리스트링 방식보다 깔끔함
- CLAUDE.md를 프로젝트 루트에 두면 Claude Code 세션 시작 시 자동으로 컨텍스트 주입
