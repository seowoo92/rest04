### 2. 네비바 드롭다운 구현
- 메인메뉴 4개(회사소개/서비스/이용후기/문의하기)에 호버 시 드롭다운 표시
- `onMouseEnter/Leave`로 드롭다운 열림/닫힘 제어
- 드롭다운 항목 클릭 시 해당 라우트로 이동
- 모바일 햄버거 메뉴 구현
- 로고를 SVG 파일 대신 JSX 인라인 컴포넌트로 구현
  (아이콘: 코랄 큰 원 + 머스타드 작은 원 + "곁에" 텍스트)

### 3. 공통 컴포넌트 구현
- **PageHeader.jsx**: 모든 서브 페이지 공통 헤더 컴포넌트
  - props: category(상단 라벨), title(제목), bgText(배경 대형 텍스트)
  - 배경 아이보리, 오른쪽에 대형 회색 영문 텍스트 (opacity 0.09)
  - 하단 구분선: 얇은 전체 라인 + 왼쪽 머스타드 포인트 선
  - 텍스트 fadeSlideUp 애니메이션
- **DarkGlow.jsx**: 다크모드 전용 배경 글로우 효과
  - Canvas API + RequestAnimationFrame으로 구현
  - 코랄(#FF6F5E) + 머스타드(#F5B23E) RadialGradient 글로우 2개
  - MutationObserver로 다크모드 실시간 감지
  - 홈(/) 제외, 모든 서브 페이지에 적용

## 트러블슈팅

| 문제 | 원인 | 해결 |
|------|------|------|
| 히어로 배경 이미지 안 보임 | GitHub 업로드 시 파일 손상(2B) | VS Code에서 직접 드래그 앤 드롭으로 `src/assets/` 에 추가 |
| 배포 후 서브 페이지 404 | GitHub Pages SPA 라우팅 미지원 | `public/404.html` 리다이렉트 스크립트 추가 |
| 다크모드 버튼 텍스트 안 보임 | 하드코딩 색상 `#2A2D43` | CSS 변수 `var(--text)`로 교체 |
| 스냅 스크롤 튕김 현상 | CSS mandatory 방식의 강제 이동 | JS debounce + 방향 감지 방식으로 교체 |
| GitHub Pages 배포 안 됨 | Pages 브랜치가 main으로 설정됨 | Settings > Pages에서 gh-pages 브랜치로 변경 |

## 배운 것
- `react-router-dom` `basename` 설정으로 GitHub Pages 하위 경로 라우팅 처리
- CSS 변수(`:root`, `.dark`)로 다크/라이트 테마 전환 구현
- Canvas API + `requestAnimationFrame`으로 부드러운 배경 애니메이션 구현
- `MutationObserver`로 DOM 클래스 변화 실시간 감지
- `IntersectionObserver` 대신 직접 `offsetTop` 계산으로 스냅 스크롤 구현
- GitHub Pages는 SPA를 기본 지원 안 해서 `404.html` 우회 필요
