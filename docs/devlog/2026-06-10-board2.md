## 1. 댓글 기능 구현

### CommentSection.jsx (src/components/CommentSection.jsx)
공지사항·자유게시판 상세 페이지 공용 댓글 컴포넌트.

**기능:**
- 댓글 목록 로드 (`r04_comments` where `post_id = id`, 오래된 순 정렬)
- 로그인 유저 댓글 작성 (Enter 키로 빠른 등록, Shift+Enter 줄바꿈)
- 본인 댓글 또는 admin 삭제 가능
- 비로그인 시 "로그인 후 댓글을 작성할 수 있습니다" 안내
- admin 작성 댓글에 "답변" 배지 표시 (`is_answer` 필드 활용)
- `profile.nickname` 자동 적용 (별도 입력 불필요)

**적용 페이지:** NoticeDetail.jsx, FreeDetail.jsx
```jsx
{notice && <CommentSection postId={id} />}
```

**author_name 처리:**
```js
const authorName = profile?.nickname || user?.email?.split('@')[0] || '회원'
```

## 2. 조회수 자동 증가

상세 페이지 진입 시 `r04_increment_view` RPC 함수 호출.

```js
supabase.rpc('r04_increment_view', { post_id: id })
```

- `security definer` 함수이므로 비로그인 사용자도 조회수 증가 가능
- 게시글 로드와 병렬 실행 (await 없이 fire-and-forget)
- 목록 페이지의 `view_count` 컬럼에 실시간 반영

## 3. 회원가입 닉네임 입력 폼

**Login.jsx 수정:**
- 회원가입 모드(`mode === 'signup'`)에서만 닉네임 입력 필드 노출
- 비워두면 이메일 앞부분을 자동 닉네임으로 사용
- 닉네임은 `signUp(email, password, nickname)`으로 전달
- `user_metadata.nickname`에 저장 → 최초 로그인 시 `r04_profiles.nickname`에 반영

```jsx
{mode === 'signup' && (
  <input placeholder="닉네임 (비워두면 이메일 앞부분 사용)" maxLength={20} ... />
)}
```

- 로그인↔회원가입 모드 전환 시 닉네임 필드 초기화

## 4. DarkGlow 개선

### 문제
기존 글로우 크기(600px/500px)가 너무 커서 모서리에 배치해도 중앙까지 번져 보임.

### 해결
| 항목 | 이전 | 이후 |
|------|------|------|
| 코랄 글로우 크기 | 600×500px | 380×320px |
| 머스타드 글로우 크기 | 500×420px | 340×280px |
| 코랄 위치 | left: -8%, top: -10% | left: 0%, top: 5% |
| 머스타드 위치 | right: -8%, bottom: -12% | right: 2%, bottom: 8% |
| 애니메이션 속도 | 14s / 18s | 7s / 9s |
| 이동 범위 | ±200px | ±80~160px (각 모서리 영역 안) |
